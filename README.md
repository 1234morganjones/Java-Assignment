# Java-Assignment

Project Overview 
this project is a stock management system that is developed using java for the GUI and object oriented programming principles. This application allows users to create and manage different stock items including navigation systems, engine parts and tyres.

The application demonstrates object oriented program concepts such as inheritence, polymorphism, encapsulation and method overriding.

set up instructions
Requirements
. Java JDK 17 or later
IntelliJ IDEA, eclipse or VS Code

1. Open code in one of the above IDE'S
3. Compile the java files
4. run StockGUI class

usage instructions
create an item 
first enter the stock code, price and quantity, then press the create item button. For example the code NS101, Price 99.99 and quantity of 10. You can then add stock to this by entering the stock code and enter the amount of stock you want to add then press the add stock button. To sell stock it is the same but press the sell stock button. Then updating the price you enter the stock code, enter new price then press the update price button.
